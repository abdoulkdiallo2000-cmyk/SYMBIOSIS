# SYMBIOSIS-Zero protocol v1.0 — 2026-09-13

Publication of a proposed protocol authorized by the project lead. Not independently validated, preregistered or cleared for recruitment. Protocol, repository and white-paper versions are independent.

H1–H5, parallel controls, randomization, outcomes, failure criteria, exploratory SBI and the Zero/1/2/N relationship are now specified. Pilot, power simulation, final sample size, implementation and ethics review remain prerequisites.

The following audit records the pre-publication file revisions and the changes proposed and authorized for this release. References to unpublished status inside this historical audit describe preparation, not current release status.
