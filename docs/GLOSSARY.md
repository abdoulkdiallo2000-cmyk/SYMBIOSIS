# Glossaire transversal SYMBIOSIS

| Terme | Définition de travail |
|---|---|
| Intelligence artificielle (artificial intelligence, AI ; IA en français) | Système artificiel utilisé comme benchmark ou assistance ; aucune conscience n’est présupposée. |
| SYMBIOSIS-Zero (SZ) | Premier niveau expérimental, utilisant des interfaces conventionnelles et une coopération volontaire, traçable et réversible. |
| Mesure préalable (PRE) | Phase humaine sans assistance, avant randomisation, servant de référence. |
| Humain seul (H) | Bras humain sans assistance artificielle. |
| Humain avec intelligence artificielle classique (H+AI) | Bras assisté sans l’architecture structurée complète de SYMBIOSIS-Zero. |
| Intelligence artificielle seule (AI) | Benchmark informatique indépendant, pas un bras humain. |
| Mesure après séparation (POST) | Phase humaine sans assistance après la coopération, immédiatement puis à sept jours lorsque prévu. |
| Indice de bénéfice symbiotique (Symbiotic Benefit Index, SBI) | Architecture d’évaluation à portes obligatoires, puis profil de bénéfice ; aucun score compensatoire global n’est validé à ce stade. |
| Gain apporté par la contribution humaine (Human Contribution Gain, HCG) | Gain marginal attribuable à l’information spécifiquement humaine dans une ablation comparable. |
| Gain apporté par la contribution de l’intelligence artificielle (AI Contribution Gain, AIG) | Gain marginal attribuable à l’information analytique artificielle dans une ablation comparable. |
| Taux de résolution appropriée des désaccords (Appropriate Disagreement Resolution rate, ADR) | Proportion de désaccords humain–IA où la décision finale retient la source correcte lorsqu’une seule l’est. |
| Plus petit effet d’intérêt (Smallest Effect Size of Interest, SESOI) | Effet minimal jugé scientifiquement ou pratiquement pertinent ; paramétrique jusqu’au gel préenregistré. |
| H1–H5 | Noyau confirmatoire futur : augmentation, complémentarité, agence/provenance, résistance aux mauvais conseils, réversibilité. |
| H6 | Calibration mutuelle ; exploratoire. L’étude principale est non adaptative ; l’adaptation est une extension distincte contrôlée. |
| H7 | Expérience et intégrité humaines ; porte obligatoire, non compensatoire. |
| H8 | Subjectivité complémentaire ; module exploratoire. |
| H9 | Transparence fonctionnelle de l’intelligence artificielle ; porte obligatoire. |
| STOP SYMBIOSIS | Ensemble de trois commandes : refus/désobéissance, pause/ralentissement, arrêt complet. |
| I_H ≠ I_AI | Notation indiquant que les ensembles d’informations accessibles à l’humain et à l’intelligence artificielle peuvent différer dans le protocole ; aucune thèse métaphysique n’est impliquée. |
