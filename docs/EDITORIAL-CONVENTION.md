# Convention éditoriale transversale SYMBIOSIS

Cette convention s’applique à l’ensemble du projet SYMBIOSIS, y compris les futurs documents, les synthèses publiques et les documents techniques.

- À la première occurrence, écrire le **terme complet en français**.
- Ajouter le terme anglais et l’abréviation entre parenthèses seulement lorsqu’ils sont utiles.
- Employer ensuite l’abréviation uniquement si elle améliore réellement la lisibilité.
- Dans les textes publics, privilégier le terme complet.
- Dans les tableaux, équations, scripts et figures, les codes courts sont acceptables à condition d’être définis dans la légende ou le glossaire.
- Toute nouvelle abréviation stable doit être ajoutée au glossaire transversal.
- Les codes expérimentaux H, AI, H+AI, SZ, PRE et POST peuvent être conservés dans les tableaux internationaux, mais leur signification doit être rappelée dans chaque document autonome.
